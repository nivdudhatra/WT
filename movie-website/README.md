# Movie Website

This project is a simple movie detail website that allows users to browse movies, view details, manage their favorites, read reviews, and contact the site administrators.

## Project Structure

The project consists of the following HTML files:

- **index.html**: The homepage of the movie website, featuring a welcome message and navigation links to other pages.
- **movies.html**: A listing of available movies, including titles, posters, and links to individual movie details.
- **movie-details.html**: Detailed information about a specific movie, including title, synopsis, cast, release date, and media.
- **favorites.html**: A list of movies that users have marked as favorites or added to their watchlist.
- **reviews.html**: A section for user reviews and ratings, including a form for submitting new reviews.
- **contact.html**: A contact form for users to reach out to the website administrators or provide feedback.

## Setup Instructions

1. Clone the repository or download the project files.
2. Open the `index.html` file in a web browser to view the homepage.
3. Navigate through the website using the provided links to explore movies, details, favorites, reviews, and contact options.

## Features

- User-friendly interface for browsing movies.
- Ability to mark movies as favorites.
- Section for user-generated reviews and ratings.
- Contact form for user feedback.

## Technologies Used

- HTML for structure and content.
- CSS (optional) for styling (not included in this project).
